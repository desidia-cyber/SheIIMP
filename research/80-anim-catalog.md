# 80 — Animation catalogue (`AnimSequence` / `AnimMontage` under `/Game/Sparta/Characters/`)

Generated by `research\scripts\anim_catalog.py` from `raw\index.sqlite3` (dump A, see `00-sources.md`), rendered by `scripts\make_anim_report.py`. The full machine-readable table is `research\slices\anim_catalog.csv`; the same rows are laid out as markdown in `80-anim-catalog-part1.md` (AnimSequence) and `80-anim-catalog-part2.md` (AnimMontage).

## Method

```sql
SELECT type, path FROM obj WHERE type IN ('AnimSequence','AnimMontage') AND path LIKE '/Game/Sparta/Characters/%' ORDER BY path
```

`category` is a **guess derived from the asset path**, never from playing the animation:

1. the asset path is split into folder segments;
2. each rule is a set of *exact folder names*; the first rule (in the order printed below) that finds one of its names in the path wins;
3. if no folder rule matches, the asset **name** is tested against the same word list;
4. otherwise the row is `other`.

The folder-name vocabulary was measured first (`scripts\anim_folders.py` prints every folder segment under the prefix together with how many animation assets live under it), so the rule table uses names that actually occur in this game rather than guesses.

**Deviation from the brief:** the brief suggested the buckets `locomotion/attack/dodge/hit/death/idle/interact/other`. The real folder tree has unambiguous folders that do not fit those seven (`Riposte` 290 assets, `VO` 131, `Parry`, `Block`, `Harden`, `Traversal`, `Cinematic`), so those got their own buckets and the `matched_by` column shows whether a row came from a folder (`folder`), from the asset name (`name`) or from nothing (`none`).

## Notes that matter for a co-op mod

* The shipped mod identifies a montage segment by *sequence path + position* at the sending client and plays the same `AnimSequence` on the receiving side (`docs\HANDOFF.md` §10), so the asset paths in these tables are the identifiers that travel between clients.
* `_Montage`-suffixed assets are the montages built on the `A_*` sequence of the same name; both appear in the tables, which is why pairs are visible.
* `Shells\_Shared\Animation\Locomotion\` is the shared locomotion set used by the mod (`A_Shared_Idle_H`, `..._Walk_Fwd_H2`, `..._Sprint_800_H2`); per-shell and per-weapon locomotion lives in the same folder tree under each shell/weapon name.
* 220 rows were categorised from the asset *name* and 447 rows had no match at all (`other`/`vo` folders like `RBF`, `MH`, `SkMesh`, `Temp`); those are the ones to treat as unclassified.
