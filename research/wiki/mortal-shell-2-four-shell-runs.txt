Mortal Shell 2 Four Shell Runs: What Changes and What Does Not 
Skip to content
 Four shells, one map
 Replaying Mortal Shell 2 on different Shells: how each Shell changes the bosses, what stays the same, and how NG+, Mether's Severance and Night Mode help.
Last verified 2026-10-15 
 Players with multiple clears describe the same thing: a new Shell changes how you fight, not where you go. If you are planning a second run – or a New Game Plus on a different body – this is what actually changes.
 What changes with each Shell
 Shell How bosses change 
 Tiel
 Clones pull aggro – Sir Isaac, Monolith and Zmey become timing fights instead of survival fights
 Proxima
 Biosampler closes distance – Hexapod and Monolith get easier, crowds get harder
 Eredrim
 Stagger and executions – humanoid bosses fall over constantly
 Lazlo
 You can tank grabs (Malborn Offspring) but Sir Isaac’s double hits punish you
 Genessa
 Doubles carry Malborn Offspring; Stray form gives a second life
 Sariel
 Pain-to-Grey-Health loop rewards staying aggressive
 Smert
 Miracle opens free damage windows at a health cost
 Gragu
 Kill-fuelled healing makes horde areas trivial
 What does not change
 The map. Corridors, jump gates and Bone Portals are the same on every Shell.
 Harden and Seals. Every Shell still relies on them.
 The last boss’s grab. It is a dodge check on every Shell (though it got more wind-up on 13 October).
 Making a second run worth it
 Use New Game Plus. All eight Shells, their bonds and upgrades, your weapons and Tarstones carry over; enemies hit harder and punish windows shrink.
 Respec instead of restarting. Mether’s Severance (5,000 coins from Merrick’s Rare Findings) resets the Shell you are bonded to and refunds every Glimpse spent on it.
 Pair the Shell with a new weapon. A Tiel run with the Black Needle plays nothing like Tiel with the Axe and Dagger.
 Add Night Mode if you want the hardest version: light the Gloombound Flame at the top of Marrow Keep and talk to Thestus.
 Patch notes to know
 Lazlo’s Temperament perk had an infinite loop (fixed 14 September), Genessa’s Augmentation lost infinite Resolve and Doubles (6 September), and Sariel’s Thornfall, Agonize and Affliction were buffed in the same update.
