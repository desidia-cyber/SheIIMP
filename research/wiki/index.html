Mortal Shell II PC launch checklist

Check the official Mortal Shell II PC requirements before launching the game on PC. The retail listing requires an SSD, 16 GB RAM and an RTX 2060 SUPER or RX 6600 class GPU. This wiki never hosts game files.

  • Windows 10/11 · 16 GB RAM · DX12
  • RTX 2060 SUPER / RX 6600 class GPU
  • 70 GB free space · SSD required
  • Violence, blood sprays, executions, firearms
